# CS351 Project 2 Documentation

## Project overview

A full-stack online store built with React, Express, and MongoDB Atlas. Customers can browse products, manage a shopping cart, and place orders.

## Live website

(https://cs351-store-528777533929.us-west1.run.app/)

## Features

- Browse products and view product details
- Create an account and log in
- Add products to a shopping cart
- Check out and view order history

## Code organization

- `client/` — React and Vite frontend
- `server/` — Express API, routes, controllers, and session management
- MongoDB Atlas — stores application data

## Main API routes

The Express API provides routes for products, user accounts, and orders. Refer to the server’s route files for the exact endpoints and request details.
